# Carpeta de Modelos 3D (`/public/models/`)

Actualmente incluye `avatar.fbx` (un modelo FBX 7.4 con pista de animación `Idle` integrada para que el proyecto funcione de inmediato con 0 errores de consola).

Para usar tu propio personaje (ej. de Mixamo):
1. Descarga tu modelo con animación **Idle** en formato **FBX Binary (.fbx)**.
2. Reemplaza el archivo `public/models/avatar.fbx` manteniendo el mismo nombre.
